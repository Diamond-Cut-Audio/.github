# Diamond Cut Audio — restoration chain for owned source files

Diamond Cut Audio keeps one named board on the desk: the live restoration chain, the noise pass in front of you, and a short note the next lab can read. Extra sources wait for their own title.

## How Diamond Cut Audio Sits

Diamond Cut Audio does not replace the player, the unlabeled source pile, or the generic noise gate you already keep. It sits beside them as a named lab desk for one job: which restoration chain is live, which noise tools still match the forensic audio pass on a file you may work, and what the next person should read.

If two people share a lab PC, each keeps a Diamond Cut Audio style of their own. Extra sources wait for their own title instead of crowding the live chain.

A first visit should be one short noise pass on a file you are allowed to work, then the same Diamond Cut Audio lab desk the next day. That is enough to see if the owned source file holds.

## Traffic Light

| Signal | On the Diamond Cut Audio board | What you do |
|--------|----------------------|-------------|
| Green | Named lab, short live chain | Continue the same restoration |
| Amber | Two sources mixed in one noise pass | Split the chain before a large change |
| Red | No title, no note, sources unlabeled | Stop and name the lab desk first |
| Clear | Handoff written, live sources few | Close Diamond Cut Audio and leave the lab desk |

## Open Order

1. Open the last Diamond Cut Audio lab desk, not a new empty restore session.
2. Read the noise tools and the last handoff for the file you may work.
3. Finish one visible restoration pass inside Diamond Cut Audio.
4. Write what changed, then close with fewer unlabeled sources than you found.
5. If the chain feels crowded, drop anything that belongs to a different owned source file.
6. Confirm Diamond Cut Audio forensic audio still sits on a file you are allowed to work.

## After a Week

A week in Diamond Cut Audio is not a larger unlabeled source pile. It is the same title, a shorter live restoration chain, and a note that still makes sense before the next noise pass on a file you are allowed to work. Take finished sources off the live set so the next visit starts on the lab desk that is still open.

Other programs stay where they are. Diamond Cut Audio only keeps the path back: desk name, restoration chain, noise tools, handoff.

Leave Diamond Cut Audio with a quieter lab desk than the one you opened. The next visit should start on that owned source file, not in a search.

## Sign-off

- [ ] A second person can read the lab handoff
- [ ] The last Diamond Cut Audio restore session still opens after a restart
- [ ] Finished sources are off the live Diamond Cut Audio set

## Field Note

Diamond Cut Audio is easier to trust when the lab desk stays smaller than the unlabeled source pile it came from. Name the restore session, keep the live chain, finish one visible noise pass on a file you may work, and write what changed.

The same loop fits a home archive, a client restore, or a shared lab PC. Open the last Diamond Cut Audio lab desk and continue. Do not rebuild the restoration chain from scratch.
